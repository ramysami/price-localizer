# Price Localizer

A Chrome extension (Manifest V3) that finds prices on any web page and rewrites them in your
currency — **EGP by default** — using up-to-date exchange rates. Converted prices are shown in
**green** so you can tell at a glance what was changed; hover one to see the original price and
the rate used.

## Install

1. Open `chrome://extensions`.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and pick this folder (`price-localizer`).
4. Pin the extension and click its icon to choose your currency.

Pages that were already open need a reload before prices convert.

## Features

- Detects symbols (`$ € £ ¥ ₹ ₺ ₪ E£ R$ C$ ج.م …`) and ISO codes (`USD 49`, `49 SAR`) before or
  after the number.
- Understands number formats from different locales: `1,234.56`, `1.234,56 €`, `1 234,50 €`,
  `CHF 1'250.50`, `₹2,49,999`, Arabic-Indic digits (`٢٥٠ ج.م`), ranges (`$10–20`) and
  magnitudes (`£5m`, `$1.2 billion`).
- Handles prices split across elements (Amazon-style `$` `24` `99`, `$19<sup>99</sup>`).
- Keeps up with dynamic pages (infinite scroll, carts, SPA navigation) and open shadow DOM.
- Everything is reversible: changing the currency, turning the extension off or pausing it on a
  site restores the original prices without a reload.
- Leaves prices already in your currency alone, and skips inputs, editors and code blocks.

### Settings (popup)

| Setting | Default |
| --- | --- |
| Convert prices to | EGP |
| On / off everywhere, per-site pause | On |
| Highlight colour | Green `#16a34a` |
| Show currency as (symbol / short symbol / code) | Symbol |
| What a plain `$` means (guess from site's country domain, or a fixed currency) | Guess — `.ca` → CAD, `.com.au` → AUD, otherwise USD |
| Round to whole numbers | Off |
| Show the original price on hover | On |

## Exchange rates

Rates are fetched by the background service worker and cached in `chrome.storage.local`:

1. **[ExchangeRate-API](https://www.exchangerate-api.com)** open endpoint (`open.er-api.com`), no
   API key needed, ~165 currencies including EGP. The response says when the next update is due,
   and the extension fetches the new set as soon as it's published.
2. **[Currency API](https://github.com/fawazahmed0/exchange-api)** (jsDelivr, then Cloudflare
   mirror) as a fallback. After a fallback, the primary is retried hourly.

The worker checks every 30 minutes, and whenever a page or the popup opens with stale rates. The
refresh button in the popup forces a fetch. If every source fails, the last saved rates stay in
use and the popup shows the error.

Both sources publish daily reference rates (not live trading rates). Coinbase's live API was
considered, but its values for pegged currencies drift from the peg (e.g. SAR 3.76 vs 3.75).

## Project layout

```
manifest.json
src/shared.js       currency tables, price regex, parsing and formatting (used everywhere)
src/content.js      scans the page, rewrites prices, watches for changes, reverts
src/background.js   fetches and caches exchange rates
popup/              settings UI
icons/              generated by tools/make_icons.py
test/parse.test.mjs unit tests for detection and parsing   → node test/parse.test.mjs
test/demo.html      demo page running the real content script with a stubbed chrome API
test/popup-demo.html popup preview with stubbed chrome APIs
```

To try the demos, serve the folder (`python3 -m http.server`) and open `/test/demo.html`.

## Known limitations

- Prices drawn in images, canvas, or with the currency symbol in CSS `::before` aren't detected.
- `kr` is only converted on Swedish, Norwegian, Danish or Icelandic domains, because it's
  ambiguous elsewhere.
- Short codes that are also everyday words (`TRY`, `ALL`, `PHP`, `AMD`, `PEN`…) are only
  recognised through their symbols (`₺`, `₱`, …) to avoid false positives.
